# M・Sライン株式会社 コーポレートサイト

HTML / CSS / 素のJavaScript だけで作った静的サイトです。ビルドは不要で、フォルダごとサーバーに置けば動きます。

## ファイル構成

```
/
├─ index.html          トップ
├─ company.html        会社情報
├─ service.html        事業内容
├─ recruit.html        採用情報
├─ contact.html        お問い合わせ（メールの案内。フォームはありません）
├─ privacy.html        プライバシーポリシー
├─ assets/
│  ├─ css/style.css    共通CSS（色・余白・フォントは冒頭の :root で一元管理）
│  ├─ js/main.js       共通JS（ヘッダー、スマホメニュー、スクロール表示、動きの演出）
│  ├─ img/             画像（WebP＋JPG）AI生成イメージを配置済み
│  │  └─ generated-originals/  生成元PNG6点・生成プロンプト
│  └─ video/           ヒーロー動画（使う場合のみ）
├─ favicon.svg / ogp.jpg
├─ sitemap.xml / robots.txt
├─ output/MSL_generated_images.zip  生成画像一式
├─ output/previews/   PC・スマホの確認画像
├─ scripts/           画像書き出し・動作確認用（サイトの実行には不要）
└─ README.md
```

ヘッダー・フッター・締めのメッセージ帯は、各HTMLに同じマークアップを書いています。直すときは **全ページ同じように** 直してください。

## 公開前にやること

1. **noindex の削除**：確認用（GitHub Pages）として検索結果に出ないよう、全HTMLの `<meta name="robots" content="noindex, nofollow">` を入れています。本番公開時は必ず削除してください。
1. **ドメインの置き換え**：全ファイルの `https://www.example.com/` を本番のドメインに置換（HTMLの canonical / OGP / JSON-LD、sitemap.xml、robots.txt）。
2. **ロゴ**：今はヘッダー・フッターのロゴを外し、社名の文字だけにしています。正式なSVGが届いたら、ヘッダーとフッターの `.logo` の中に戻し、`favicon.svg` も差し替えて、`style.css` の `--color-brand` を正確なカラーコードにしてください。
3. **「※ここに○○が入ります」** と書かれた点線の枠（`note-dummy`）を、すべて実際の内容に差し替えてください。全文検索で `note-dummy` と `【要確認】` を探すと見つかります。
4. **ogp.jpg** は生成した倉庫イメージ（1200×630）です。本番の実写真が用意できたら差し替えてください。

## 画像の差し替え方法

`assets/img/` のファイル名に必要なサイズが入っています（例：`hero_1920x1080`）。

| ファイル名 | 使う場所 |
|---|---|
| hero_1920x1080 / hero_sp_750x1334 | トップのファーストビュー（PC / スマホ） |
| about_01_800x1000 / about_02_800x600 | トップ ABOUT |
| service_keep / manage / connect_1200x800 | トップのカード、事業内容の各サービス |
| page_company_1920x800 / page_service_1920x800 / page_recruit_1920x800 | 下層ページの写真帯（採用情報は staff.png を横長に切り出し） |
| generated-originals/*.png | 生成した6種類の元画像（サイトから直接は読み込みません） |
| base_hiruzen / base_okayama_1280x720 | 会社情報の拠点カード |

- **同じファイル名**で、`.jpg` と `.webp` の両方を上書きしてください（WebP は `cwebp` や Squoosh で作れます）。
- 縦横比が同じなら、サイズが違っても大丈夫です。比率を変える場合は、HTML の `width` / `height` も合わせて直してください。
- 写真の色味は少しあたたかく、明るめにそろえてください。
- 画像を変えたら、その `<img>` の `alt`（写真の説明）も実際の内容に直してください。

## ヒーロー動画を使う場合

1. PC用（横長）を `assets/video/hero_pc.mp4`、スマホ用（縦長）を `assets/video/hero_sp.mp4` として置く。
2. `index.html` のファーストビューにある `<video>` 2行のコメント（`<!--` `-->`）を外す。

自動再生・ミュート・ループ・playsinline は設定済みです。「視差効果を減らす」設定の閲覧者には、静止画が表示されます。

## お問い合わせ（メール）

フォームは使わず、メールで受け付けます。`contact.html` に、ご相談の内容（倉庫保管／物流センターの運営／輸送車両の手配／その他）ごとのボタンがあり、押すとメールアプリが開いて、件名と記入欄が入った状態になります。採用ページの「メールで応募する」も同じ仕組みです。

- 受付のメールアドレスは `msline.081507@gmail.com` です（元の指示書にあったものです。お客様に確認済みです）。変えるときは、`contact.html`・`recruit.html`・`company.html` の `mailto:` と、`index.html` の構造化データ（`"email"`）を全文検索で置換してください。
- 件名や記入欄の文面は、`mailto:` のリンクの中（`subject=` と `body=`）にURLエンコードされて入っています。直すときは、日本語のまま書いて変換してください（例：Pythonの `urllib.parse.quote`）。
- メールアプリが設定されていない閲覧者のために、アドレスは文字でも表示しています。
- お問い合わせの導線をすべてなくす場合は、各ページのヘッダー・フッター・締めの帯にある `data-contact` の要素を削除し、`contact.html` を削除して、`sitemap.xml` の1行も消してください。締めの帯は自動で電話番号の表示に切り替わります（CSS の `:has()`）。

## 採用情報ページ（recruit.html）

- 構成：写真帯 → メッセージ → 働く環境（3つの特長） → 募集要項（職種カード） → 選考の流れ → 応募の案内（電話＋メール応募）。
- 職種を増やすときは `<article class="job">…</article>` を丸ごとコピーして、番号と中身を書き換えてください。募集がない職種は削除します。
- 「メールで応募する」は、件名「【採用応募】」と記入欄の入ったメールを作成します。
- 電話だけにするときは、応募の案内のボタン（`data-contact`）を削除してください。
- 募集要項が確定したら、Google しごと検索に載るよう、職種ごとに JobPosting の構造化データ（JSON-LD）を `<head>` に追加するのがおすすめです。
- 全ページのヘッダーとフッターに「採用情報」のリンクを追加済み。採用を一時的に止めるときは、各ページの `recruit.html` へのリンクと sitemap.xml の1行を削除してください。

## 今回の実装について

- HTML / CSS / 素のJavaScriptで実装。ビルド・外部JSライブラリは不要です。
- 指示書の灰色プレースホルダー指定より、今回の「画像生成して配置」の依頼を優先しました。
- 内蔵imagegenで倉庫内・作業員・山あいの倉庫・検品作業・トラック・市街地の倉庫の6種類を生成。生成プロンプトは `assets/img/generated-originals/manifest.json` に保存しています。
- 配信用画像は `assets/img/`、元PNGは `assets/img/generated-originals/`、まとめて渡せるZIPは `output/MSL_generated_images.zip` です。
- 生成画像は架空のイメージです。全ページのフッターと画像のaltで明記しています。実際の拠点・所有車両・社員を証明する写真ではありません。
- トップのテーマを「近くて、確か。」として、余白、生成り、ネイビー、青を統一しました。
- 代表の肖像・未確定の沿革は作りません。理念文は確認用の案として表示しています。
- モバイルメニューはTabのフォーカス循環・Escape・背景操作防止・PC幅への変更時の解除に対応。

## 手元での確認

`index.html` をブラウザーで開いて確認できます。ローカルサーバーを使う場合は、このフォルダーで `python3 -m http.server 8765 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8765/` にアクセスしてください。

確認用の `scripts/check_site.cjs` はNode.js・Playwright・Chromeがある制作環境向けです。必要に応じ `PLAYWRIGHT_MODULE` と `CHROME_PATH` を指定できます。静的サイトの公開にはこれらは不要です。

## 公開するファイル

6つのHTML、`assets/css/`、`assets/js/`、`assets/img/` 直下の配信用画像、`favicon.svg`、`ogp.jpg`、`sitemap.xml`、`robots.txt` をアップロードしてください。元画像フォルダー、制作プロンプト、`scripts/`、`output/` は公開不要です。

ドメイン・正式ロゴ・お問い合わせ用メールアドレス・ポリシー・業務詳細を確定するまでは公開前の制作版です。Lighthouseの90点目標とSafari・Firefox等の実機確認は公開環境で別途実施してください。

## 動きと背景の模様

- 動き（`style.css` の 17・19 章、`main.js` の 3-2）：ファーストビューの視差、見出しの線、写真のシャッター、数字のカウントアップ、流れる文字の帯、拠点マップのルート線など。「視差効果を減らす」設定の閲覧者には動きを付けません。
- 背景の模様：無地の面を減らすため、約半分のセクションに入れています。クラスを付け外しして調整できます。`bg-topo`（等高線）、`bg-grid`（格子）、`bg-route`（点線のルート）、`bg-dots`（ドット）、`bg-word` ＋ `data-word="英字"`（スクロールで流れる大きな英字）。模様の画像は `assets/img/bg_topo.svg`・`bg_route.svg` です。
